무료 오픈소스 · macOS · Apple Silicon

회의 녹음을 내 Mac 안에서 텍스트로.

Tractus는 녹음을 이 Mac에서 바로 한국어·영어 텍스트로 바꾸고, 참석자를 구분하고, 근거가 달린 요약과 검색, AI 질문까지 하는 로컬 회의록 앱입니다. 오디오는 Mac 밖으로 나가지 않습니다.

Mac용 다운로드 GitHub에서 보기 v0.4.0 · macOS 14.4 이상 · Apache 2.0

녹음 노트 → 노트 완성(내 메모 + 대화 내용) → Claude Code에서 회의 물어보기 (가상 데이터)

왜 Tractus인가

녹음은 내 Mac에, 근거는 문장마다.

  1. 01

    무거운 일은 모두 이 Mac에서

    녹음, 음성 인식, 참석자 구분, 스마트 검색이 Apple MLX로 내 Mac 안에서 돕니다. 오디오를 올리지 않고, 계정이나 API 키도 필요 없습니다.

  2. 02

    모든 요약에 근거 시각

    요약 항목, 할 일, AI 답변마다 근거가 된 대화의 시각이 붙습니다. 누르면 그 자리부터 다시 듣습니다.

  3. 03

    내가 가진 파일로

    노트는 오디오·JSON·Markdown 파일로 남습니다. TXT, Markdown, SRT, VTT, CSV, DOCX, PDF로 내보내고 Obsidian으로 보낼 수 있습니다.

  4. 04

    AI 에이전트의 회의 기억

    MCP 서버와 Claude Code 플러그인으로 에이전트가 내 회의를 찾아 [주간 개발 회의 00:02:11]처럼 근거를 달아 답합니다.

기능

녹음부터 믿을 수 있는 회의록까지

대면 회의와 화상 회의를 녹음하고, 받아 적은 내용을 읽고 고치고 다시 씁니다.

내 Mac에서 하는 음성 텍스트 변환

Qwen3-ASR이 한국어·영어를 자동으로 감지해 받아 적고, 영어 용어가 섞인 한국어 회의에 강합니다. 참석자를 구분하고, 한 번 이름을 붙이면 다음 녹음부터 이름을 제안합니다.

  • 노트 제목과 메모의 낱말이 분야 용어 인식을 돕습니다
  • 잘못 들은 용어를 고치면 자주 쓰는 단어로 추가하자고 제안합니다
  • 단어 싱크: 재생 중인 단어를 강조하고 단어를 눌러 그 자리부터 듣기

근거가 달린 요약과 AI 질문

회의록, 핵심 요약, 할 일 중심, 강의·세미나, 인터뷰, 아이디어 정리, 내가 쓴 요약 방법. 노트 하나나 모든 노트에 묻고, 답에는 근거 대화가 붙습니다.

  • 노트 완성: 녹음하며 대충 적은 메모에 대화 내용의 세부를 붙입니다
  • Upstage, OpenAI, Claude, Gemini, 내 Mac의 AI 중에서 고릅니다

쓰고, 정리하고, 찾기

체크박스와 서식을 쓰는 메모, 즐겨찾기·태그·폴더, 모든 노트에서 단어와 비슷한 뜻을 함께 찾는 스마트 검색(⌘K).

  • macOS 캘린더 일정으로 바로 녹음, 참석자 이름이 인식을 돕습니다
  • 라이트·다크 모드, 한국어·영어 화면, 앱 안 업데이트

자주 묻는 질문

질문

Tractus는 무료인가요?

네. Apache 2.0 라이선스의 무료 오픈소스입니다. 녹음, 텍스트 변환, 참석자 구분, 검색, 내보내기는 계정이나 API 키 없이 됩니다. 요약과 AI 질문은 직접 고른 AI 서비스(Upstage, OpenAI, Claude, Gemini, OpenAI 호환 API, 내 Mac의 AI)를 씁니다.

녹음 파일이 외부로 전송되나요?

아니요. 음성 인식, 참석자 구분, 스마트 검색은 Apple MLX로 내 Mac 안에서 돕니다. 요약이나 AI 질문을 할 때 필요한 텍스트만, 고른 AI 서비스로 보냅니다.

어떤 Mac에서 쓸 수 있나요?

Apple Silicon(M1 이상) Mac, macOS 14.4 이상입니다. 메모리 16GB 이상을 권장하고, 8GB는 저사양 구성으로 씁니다. ffmpeg가 필요합니다(brew install ffmpeg).

클로바노트 대신 쓸 수 있나요?

녹음 → 텍스트 변환 → 요약 → 검색이라는 흐름은 같지만, 음성 인식을 클라우드가 아니라 내 Mac에서 하고 노트를 내가 가진 파일로 남긴다는 점이 다릅니다. 영어 용어가 섞인 한국어 회의에 맞춰 조정했습니다.

한국어 음성 인식은 얼마나 정확한가요?

실제 한국어 회의(5.2시간)로 잰 결과, 기본 모델 Qwen3-ASR-1.7B의 글자 오류율은 9.49%로 Whisper-large-v3-turbo(14.92%)보다 오류가 36% 적었습니다. 노트 제목과 메모의 낱말, 자주 쓰는 단어를 함께 넣어 분야 용어를 더 정확하게 받아 적습니다.

Apple 서명을 받았나요?

아직 받지 않았습니다. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 시스템 설정 › 개인정보 보호 및 보안에서 '그래도 열기'를 누르세요. 자세한 내용은 설치 안내에 있습니다.
