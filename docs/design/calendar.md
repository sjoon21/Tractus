# 설계: macOS 캘린더 일정으로 녹음하기

> 상태: 구현됨 (2026-10-16, v3.38, 브랜치 `feat/calendar`). 계약은 docs/desktop.md §1(`tractus-rec calendar`)·§2.19·§3.6, 문구는 WORDS.md §4.24.

## 한 줄 요약

설정에서 캘린더를 연결하면, 진행 중이거나 15분 안에 시작하는 일정 하나가 홈에 카드로 보인다. `녹음`을 누르면 그 일정 제목으로 녹음이 시작되고, 참석자 이름은 그 녹음의 음성 인식 힌트와 참석자 이름 고르기에 쓰이며, 일정 정보는 노트에 남는다.

## 결정 (2026-10-16, 사용자 선택)

1. **홈에는 곧 시작하는 일정 하나만.** 진행 중이거나 15분 안에 시작하는 일정(종일 일정 제외) 중 시작이 가장 이른 것. 없으면 카드가 없다.
2. **참석자 이름은 세 곳에:** 그 녹음의 음성 인식 힌트(자주 쓰는 단어 목록에는 넣지 않는다), 대화 내용의 참석자 이름 고르기, 노트의 일정 정보(`event.json`, Obsidian 속성 `attendees`).
3. **알림은 하지 않는다.** 알림 권한이 필요 없다.
4. **캘린더는 설정에서 고른다.** 처음에는 모두 읽고, 끈 캘린더 ID만 저장한다.

## 읽는 쪽: `tractus-rec calendar` (EventKit, Swift)

Google·Exchange 계정도 macOS 캘린더에 추가돼 있으면 읽힌다(OAuth 없음). 권한은 `캘린더 전체 접근`이고 앱 Info.plist의 `NSCalendarsFullAccessUsageDescription`이 문구다. 녹음 프로그램은 앱의 하위 프로세스라 권한 창은 앱 이름으로 뜬다.

| 명령 | 출력 (한 줄 JSON) |
| --- | --- |
| `calendar access` | `{"access": "granted\|denied\|undetermined\|restricted\|write_only"}` (묻지 않는다) |
| `calendar request` | 권한 창을 띄우고 같은 모양 |
| `calendar list` | `{"access", "calendars": [{"id", "title", "source"}]}` |
| `calendar next --ahead 15 [--exclude ID]…` | `{"access", "events": [{"id", "title", "start", "end", "calendar", "attendees": ["이름"]}]}` |

- `next`는 끝나지 않았고 `ahead`분 안에 시작하는 일정을 시작 순으로 준다. 종일·제목 없는·취소된·내가 거절한 일정은 뺀다(제목은 200자까지 자른다). 참석자는 사람(`person`)이고 이름이 있는 사람만, 나(`isCurrentUser`)도 포함한다. **이메일은 내보내지 않는다:** 이름이 없는 초대 대상은 EventKit이 이메일을 이름에 넣으므로 `@`가 든 이름은 녹음 프로그램·앱·코어 세 곳에서 모두 뺀다.
- 권한이 없으면 `events`·`calendars`는 빈 목록이다(오류가 아니다).

## 노트에 남는 것: `event.json`

앱이 녹음을 시작할 때 녹음 폴더에 쓰고, 코어가 노트 폴더로 옮긴다(`memos.json`과 같은 방식). transcript.json은 바꾸지 않는다.

```json
{"title": "주간 개발", "start": "2026-10-16T10:00:00+09:00", "end": "2026-10-16T11:00:00+09:00", "calendar": "회사", "attendees": ["김민수", "이지은"]}
```

- 코어는 읽을 때 검사한다(`calendar_event.load_event`): 제목 1~200자, 시각은 ISO 8601, 참석자는 한 줄 80자 이하·중복 제거·50명까지. 깨졌으면 없는 것으로 본다.
- **제목:** 녹음 노트의 기본 제목이 `녹음 HH:MM` 대신 일정 제목이 된다(바로 변환·나중에 변환 모두).
- **음성 인식 힌트:** 참석자 이름을 그 노트의 변환에만 `hotwords`로 더한다(`--term`과 같다). 나중에 변환(`--into`)도 노트 폴더의 `event.json`을 읽는다.
- **참석자 이름 고르기:** 대화 내용의 참석자 메뉴에 일정의 참석자 이름을 먼저 보인다. 고르면 기존 `이름 정하기`와 같다(목소리 제안이 아니라 사용자 확정).
- **Obsidian:** frontmatter에 `attendees: [..]`.
- 내보내기 묶음(ZIP)에 `event.json`이 들어간다.

## 앱

| 위치 | 내용 |
| --- | --- |
| 설정 `캘린더` | `캘린더 연결` 단추(권한 요청) → 연결되면 캘린더 목록 스위치. 거부됐으면 `시스템 설정 열기`. 설정 키 `calendar_enabled`(기본 꺼짐: 연결 전에는 아무것도 묻지 않는다)·`calendar_hidden`(끈 캘린더 ID) |
| 홈 | 연결돼 있으면 1분마다 `calendar next`를 부른다. 카드: 일정 제목, `10:00–11:00 · 진행 중`/`5분 뒤`, 참석자 수, `녹음` 단추 |
| 녹음 | `rec_start(flags, target, event)`가 녹음 폴더에 `event.json`을 쓴다 |

## 하지 않는 것

- 알림, 메뉴 막대 표시, 일정 목록 화면, 일정과 기존 노트 이어 붙이기.
- 참석자 이메일 저장, 캘린더 쓰기.
- 녹음을 자동으로 시작·종료하기.
