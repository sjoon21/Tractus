# 설계: 한국어 숫자 표기 바꾸기 (ITN, 0.4.3 후보)

> 상태: 개발 (2026-10-22, 브랜치 `feat/korean-itn`). 모듈 `src/tractus/itn.py`, 측정 `bench/itn_eval.py`.

## 한 줄 요약

음성 인식이 한글로 적은 한자어 수를 숫자로 바꾼다("삼십 프로" → "30프로", "이천이십칠 년" → "2027년"). 틀리게 바꾸지 않도록 보수적으로만 바꾼다.

## 왜 하나

- **표기 차이가 오류의 약 9%다.** AI Hub 발화 단위 결과(1.7B 8bit)를 철자 전사 기준으로 채점하면 CER 9.48이다. 발음·철자 중 가까운 쪽으로 채점하면 8.62로 내려가고, 그중 0.74%p가 숫자다(`score.cer_best`, docs/internal 연구 메모 §4.1).
- **Qwen3-ASR은 숫자 셋 중 둘을 한글로 적는다**(한글 407, 숫자 195). 읽기 불편하다.
- **회의록 숫자 대조가 틀린 경고를 낸다.** `minutes.unverified_numbers`는 근거에서 숫자 문자(`\d+`)만 찾는다. 대화 내용이 "삼십만"이고 AI가 "30만"을 쓰면 맞는 숫자에도 `숫자 확인`이 붙는다.
- 외부 자료도 같은 결론이다. 콜봇 STT 글(2026-07)은 숫자·금액·날짜를 별도 카테고리로 재고 ITN을 함께 적용하라고 권한다.

## 결정

1. **규칙 기반, 새 의존성 없음.** NeMo 텍스트 정규화 같은 FST 라이브러리는 pynini·OpenFST를 끌어와 번들(wheel만)에 맞지 않는다. 필요한 것은 한자어 수 + 단위라 코드 한 파일이면 된다.
2. **보수적인 규칙.** 그대로 두는 것보다 틀리게 바꾸는 것이 나쁘다.
   - **바꾸는 것:** 단위(`UNITS`: 원·명·개월·년·분·프로·퍼센트·조 …) 앞의 한자어 수. 단위가 없으면 세 글자 이상이면서 십·백·천·만·억·조가 든 수, 또는 두 글자 "○십".
   - **단위 뒤에는 조사나 문장 끝이 와야 한다**(`PARTICLE_START`). "오 박사", "삼 개발", "일 배포", "사 회의"는 단위 글자로 시작하는 다른 낱말이라 그대로 둔다.
   - **한 글자 수는 띄어 쓴 단위 앞에서만 바꾼다**("오 분" → "5분"). 붙여 쓴 것은 `년·월·개월·프로·퍼센트·층·분기·주년`만 바꾼다. "오세요", "사위", "사명", "일시"는 수가 아니다.
   - **`이` 한 글자는 바꾸지 않는다.** "이 시간", "이 분", "이 점"처럼 "this"로 더 자주 쓰인다.
   - **고유어 수는 바꾸지 않는다**("두 번", "세 가지", "한번 해 보자").
   - **만·억·조는 말로 남긴다**("35만 원", "3억 5000만 원", "5조 원"). 회의록에서 흔한 표기이고 AI Hub 철자 전사와 같다. 숫자와 작은 단위는 붙이고("30분"), 큰 단위 뒤의 단위는 띄운다("5조 원").
3. **자리: `asr.Transcriber.transcribe`의 끝.** 모든 계열(Qwen3·Whisper·SenseVoice)과 실시간 자막에 똑같이 적용한다. 그래서 `text`(음성 인식 원문)가 이미 숫자로 적혀 있다. SenseVoice의 `use_itn=True`가 엔진 안에서 하는 일과 같다. 단어 싱크는 바뀐 문장으로 맞추므로 `words` 불변식이 그대로 지켜진다.
4. **회의록 대조도 근거를 ITN으로 읽는다.** 이미 만든 노트(근거가 "삼십 프로")에서도 "30"을 찾는다.
5. **설정을 두지 않는다.** 측정에서 나빠진 사례가 사실상 없어서다(아래). 끄고 싶다는 요청이 생기면 그때 더한다.

## 측정 (2026-10-22, M3 16GB, 저장해 둔 결과에 적용, 추론 없음)

AI Hub 4세션(5.2시간) 발화 단위 2,527개, 1.7B 8bit(`bench/itn_eval.py`):

| | 전 | 후 |
| --- | --- | --- |
| CER (철자 기준, 발화 단위) | 9.48 | **9.14** |
| 바뀐 발화 | — | 121 |
| 나아진 / 나빠진 발화 | — | 113 / 7 |

- **나빠진 7개는 정답 쪽이 숫자를 이중 전사 없이 한글로 적은 경우다**("천 원", "십 년" 등, 숫자 조각과 정답 포함 여부만 확인). 바꾼 숫자는 맞다.
- 규칙을 다듬는 중에 진짜로 잘못 바꾼 것 두 가지("공조" → "0조", "구조" → "9조")를 찾아 막았다. 단위 `박`("오 박사")은 쓰인 4번이 모두 오답이라 뺐다.

세션 단위(VAD 30초, 제품과 같은 자르기) CER:

| 엔진 | 전 | 후 |
| --- | --- | --- |
| Qwen3-ASR 1.7B | 9.49 | **9.33** |
| Qwen3-ASR 1.7B + 자주 쓰는 단어 | 9.36 | **9.20** |
| Qwen3-ASR 0.6B | 11.47 | **10.98** |
| BuzzASR (원래 숫자로 적는 편) | 10.29 | 10.23 |

FLEURS(낭독, 공개)에서는 1.7B 2.62 → 2.61이다. 나빠진 3건은 "천 년" → "1000년", "일만 년" → "1만 년" 같은 표기 취향이다.

## 하지 않은 것

- 소수점("삼 점 오" → 3.5), 시각("오후 세 시"), 전화번호, 고유어 수, 단독 `이`.
- 이미 변환한 노트의 `text`를 다시 쓰기(다시 변환하면 적용된다. 회의록 대조는 옛 노트에도 적용된다).
- 바꾸기 전 원문을 따로 저장하기.
