# 설계: Obsidian으로 보내기

> 상태: 구현됨 (2026-10-16, v3.37, 브랜치 `feat/obsidian-export`). 계약은 docs/desktop.md §2.18, 문구는 WORDS.md §4.23.

## 한 줄 요약

노트의 `내보내기` 메뉴에서 `Obsidian`을 누르면, 설정에서 고른 볼트의 `Tractus/` 폴더에 노트 하나가 Markdown 파일 하나로 들어간다. 다시 보내면 같은 파일을 고쳐 쓴다. 볼트에서 그 파일을 고쳤으면 덮어쓰기 전에 묻는다.

## 결정 (2026-10-16, 사용자 선택)

1. **직접 보내기만 한다.** 자동으로 따라가기(저장할 때마다 다시 쓰기)는 하지 않는다. 사용자가 누를 때 그 노트만 쓴다.
2. **Tractus 폴더 구조를 그대로 쓴다.** `볼트/Tractus/<폴더>/<하위 폴더>/2026-10-16 주간 개발.md`. 폴더 없는 노트는 `볼트/Tractus/` 바로 아래.
3. **오디오는 설정으로 고른다(기본 꺼짐).** 켜면 `볼트/Tractus/attachments/<meeting_id>.ogg`로 복사하고 노트 위에 `![[<meeting_id>.ogg]]`로 붙인다.
4. **넣는 것:** 완성된 노트(있으면, 없으면 내 메모), 요약 하나, 할 일은 `- [ ]` 체크박스, 대화 내용은 접힌 상자(`> [!note]- 대화 내용`).

## 파일 모양

```markdown
---
tractus_id: 2026-10-16_0900_ab12cd
title: 주간 개발
created: 2026-10-16T09:00:00+09:00
duration: 0:45:12
participants: [김민수, 이지은]
tags: [개발]
folder: 프로젝트
---

# 주간 개발

![[2026-10-16_0900_ab12cd.ogg]]

## 완성된 노트

### 예산 다시 확인
- p95가 800ms까지 올랐다 [00:01:23]

### 할 일
- [ ] slow query 분석 공유 — 김민수, 수요일 [00:04:10]

## 요약 · 회의록
...

> [!note]- 대화 내용
> [00:00:00] **김민수**: 네 그럼 시작하겠습니다.
```

- 완성된 노트와 요약은 이미 저장된 Markdown(`summaries/enhanced.md`·`summary.md`)을 가져와 frontmatter와 제목 줄을 빼고 제목 단계를 하나씩 내린다. 같은 내용을 두 번 만들지 않는다.
- 요약은 앱의 요약 탭에서 고른 것, 없으면 기본 요약, 그것도 없으면 처음 있는 요약이다. 노트 완성은 요약으로 세지 않는다(위에 따로 나온다).
- 메모 노트(녹음 없음)는 본문을 그대로 쓰고 대화 내용·요약 절이 없을 수 있다. 변환 전 노트는 메모와 `아직 텍스트로 변환하지 않았습니다` 안내만 쓴다.
- `participants`는 사용자가 이름을 확정한 참석자만이다(목소리 제안·`참석자 1` 같은 자동 이름은 넣지 않는다).

## 내 파일인지, 고쳤는지

`볼트/Tractus/.tractus.json`(Obsidian은 점으로 시작하는 파일을 보이지 않는다)에 보낸 파일을 적는다.

```json
{"notes": {"<meeting_id>": {"path": "프로젝트/2026-10-16 주간 개발.md", "sha256": "…"}}}
```

| 상황 | 동작 |
| --- | --- |
| 처음 보냄 | 새 파일을 쓰고 기록한다 (`created`) |
| 기록된 파일의 sha256이 같다 | 내용이 바뀌었으면 고쳐 쓴다(`updated`), 같으면 그대로(`unchanged`) |
| 제목·폴더가 바뀌어 위치가 달라졌다 | 새 위치에 쓰고 옛 파일을 지운다 (고치지 않은 우리 파일만) |
| 기록된 위치에 없다 (Obsidian에서 옮김) | `Tractus/` 아래에서 frontmatter `tractus_id`가 같은 파일을 찾는다 |
| 파일이 바뀌었다 (Obsidian에서 고침) 또는 기록이 없는데 찾았다 | 쓰지 않고 `{"status": "edited"}`. 앱이 덮어쓸지 묻고 `--force`로 다시 부른다 |
| 같은 이름의 남의 파일이 있다 | ` (2)`, ` (3)` …을 붙인다 |

## 안전

- `볼트/Tractus`가 데이터 폴더이거나 그 안, 또는 데이터 폴더가 그 안이면 거부한다(노트 원본 폴더에 파일을 쓰지 않는다).
- 지우는 파일은 `.tractus.json`에 기록된, 고치지 않은 우리 파일뿐이다. `--force`로 덮어쓸 때 옛 위치의 고친 파일은 지우지 않는다.
- 파일 이름에 못 쓰는 글자(`/\:*?"<>|`, 제어 문자, 앞의 `.`)는 공백으로 바꾼다.

## 코어·앱

| 위치 | 내용 |
| --- | --- |
| `src/tractus/obsidian.py` (새 모듈) | 파일 모양(`render`), 위치(`target`), 기록·찾기·고쳤는지(`send`) |
| `cli.py` | `tractus obsidian <노트> --vault <폴더> [--summary KEY] [--audio] [--force]` → `{"status", "path", "audio"}` |
| 앱 설정 | `obsidian_vault`(비면 아직 안 고름), `obsidian_audio`(기본 꺼짐) |
| 앱 내보내기 메뉴 | `Obsidian` 항목. 볼트를 안 골랐으면 폴더를 고르게 하고 저장한다 |

## 하지 않는 것

- 자동 동기화, Obsidian → Tractus 되읽기, 여러 노트 한꺼번에 보내기.
- Tractus에서 노트를 지울 때 볼트 파일 지우기.
- Obsidian 플러그인.
