# Tractus v0.1.0 (시험판)

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 하는 노트 앱의 첫 시험판입니다. **팀 내 시험용이고, 아직 서명·공증되지 않았습니다.**

## 받을 파일

| 파일 | 설명 |
| --- | --- |
| `Tractus-0.1.0-arm64.dmg` | 설치 파일 (약 243MB, Apple Silicon 전용) |
| `Tractus-0.1.0-arm64.dmg.sha256` | 체크섬 (SHA-256) |

SHA-256: `ab17bec005ed700e63bae0e8eb1110575de6a1e4c07cbce947fb06dd22bdd4f7`
확인: `shasum -a 256 -c Tractus-0.1.0-arm64.dmg.sha256`

## 설치

1. DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다. (관리자 암호는 필요 없습니다.)
2. 처음 실행할 때 "확인되지 않은 개발자" 경고가 나옵니다. 서명되지 않은 앱이라 정상입니다.
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"
   - 그 외: 앱을 우클릭 → 열기
   - 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/Tractus.app`
3. **ffmpeg가 필요합니다** (앱에 포함되어 있지 않습니다): `brew install ffmpeg`
4. 앱을 열면 나오는 **시작 점검**에서 모델을 받고(필수만 약 1~2.3GB, 표준 구성 약 4.6GB), 설정에서 Upstage API 키를 등록하면 요약·AI 질문을 쓸 수 있습니다.

자세한 안내는 저장소의 `docs/setup.md`(§10 "미리 만든 앱 받기")와 `README.md`를 봐 주세요.

## 요구 사항

- Apple Silicon(M1 이상), 메모리 16GB 이상 권장(8GB는 저사양 구성)
- macOS 14.4 이상은 **설계상 최소**입니다. 아래 "확인하지 못한 것"을 참고하세요.

## 이 버전에 들어 있는 것

- 녹음(일시정지·계속), 파일 가져오기, 녹음과 변환 분리("변환 전" 노트), 텍스트 노트·메모
- 참석자 구분, 단어 싱크, 요약 템플릿 6종과 직접 프롬프트, AI 질문, 검색
- 즐겨찾기·태그·폴더, 내보내기(txt, md, srt, vtt, csv, docx, ZIP, PDF), 노트 삭제(휴지통)
- 메뉴 막대 아이콘, 좌우 패널 접기, 모델 관리와 시작 점검

## 알려진 한계와 확인하지 못한 것

- 깨끗한 Mac 계정과 macOS 14~15에서는 실행해 보지 못했습니다. 최소 버전(14.4)은 앱 안 실행 파일 169개의 빌드 정보를 검사한 결과에만 근거합니다.
- 서명·공증이 없어서 처음 실행 때 보안 경고가 나옵니다. 다운로드한 파일에는 격리 표시가 붙습니다.
- 이 DMG에는 9명 이상 참석자 구분 프로그램이 들어 있지 않습니다(최대 8명). 필요하면 소스에서 빌드하세요.
- 마이크·시스템 오디오 권한 요청 창에 표시되는 이름과 일시정지 중 마이크 표시등 동작은 실제 기기에서 확인하지 못했습니다. 일시정지 중에도 마이크는 켜진 채 소리만 버려져서 macOS 마이크 표시등이 꺼지지 않습니다.
- 8bit 임베딩 모델의 검색 품질은 검증하지 않았습니다.
- 이 저장소는 비공개라서 이 릴리스는 초대된 사람에게만 보입니다.

## 업데이트

새 버전의 `.dmg`로 `Tractus.app`을 바꿔 넣으면 됩니다. 노트(`~/Tractus`), 모델, 설정, API 키는 앱 밖에 있어서 그대로 유지됩니다. 소스로 설치했다면 `git pull` 후 `scripts/update.sh`를 실행하세요.
