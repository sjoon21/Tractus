# Tractus v0.1.1

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 하는 노트 앱입니다. **팀 내 시험용이고, 아직 Apple 서명·공증은 받지 않았습니다.**

## 이번 버전

- **앱 안 업데이트.** 설정 > 업데이트에서 새 버전을 확인하고 설치합니다. 앱을 켜고 10초쯤 뒤에도 한 번 조용히 확인해 새 버전이 있으면 알립니다. 자동으로 설치하지는 않습니다.
- **AI 서비스를 여러 개 등록.** Upstage, OpenAI, Claude, Gemini, 직접 입력(OpenAI 호환, 이 Mac의 AI 포함). 서비스마다 주소·API 키·AI 모델을 두고, 요약·AI 질문마다 어느 서비스를 쓸지 고릅니다.
- **Gemini 연결 수정.** 기본 AI 모델을 `gemini-flash-latest`로 바꿨고, 서비스의 AI 모델 목록을 불러와 고를 수 있습니다.
- **스마트 검색을 Upstage로(선택).** 설정에서 고르면 노트 문장이 Upstage로 전송됩니다. 기본은 이 Mac에서 처리합니다.
- API 키는 5자부터 저장됩니다. 요약·답변 아래의 서비스 이름 표시를 뺐습니다.

## 설치

1. DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다. 관리자 암호는 필요 없습니다.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나옵니다. 서명이 Apple에 등록되지 않아서 그렇습니다.
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"
   - 그 외: 앱을 control 키를 누른 채 클릭 → 열기
   - 터미널: `xattr -dr com.apple.quarantine /Applications/Tractus.app`
3. **ffmpeg가 필요합니다** (앱에 들어 있지 않습니다): `brew install ffmpeg`
4. 시작 점검에서 모델을 받고, 설정에서 AI 서비스 키를 등록하면 요약·AI 질문을 쓸 수 있습니다.

**v0.1.0을 쓰고 있다면** 이번 한 번은 이 DMG로 직접 바꿔 넣어야 합니다. v0.1.0에는 업데이트 기능이 없습니다. 노트·모델·설정은 앱 밖에 있어 그대로 남습니다.

## 요구 사항

- Apple Silicon(M1 이상), 메모리 16GB 이상 권장(8GB는 저사양 구성)
- macOS 14.4 이상(설계상 최소)

## 확인하지 못한 것

- 앱 안 업데이트를 실제 릴리스로 끝까지 돌려 본 것은 이 버전이 처음입니다. 다음 버전이 나올 때 확인됩니다.
- 업데이트 뒤 마이크·시스템 오디오 권한을 다시 물을 수 있습니다(ad-hoc 서명이 버전마다 달라서 예상하는 것이고, 직접 확인하지는 못했습니다).
- 깨끗한 Mac(새 계정)과 macOS 14.4~15에서는 시험하지 못했습니다.
- Upstage 스마트 검색의 검색 품질은 재지 않았습니다.
- 9명 이상 참석자 구분 도우미(`tractus-diar`)는 들어 있지 않아 참석자는 8명까지 구분합니다.
