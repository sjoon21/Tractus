# Tractus v0.5.2

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 이번 버전은 변환 엔진을 고르는 화면을 다시 만들고, 녹음 중 장치가 바뀔 때 녹음이 죽던 문제를 고쳤습니다. (English below)

## 이번 버전에서 바뀐 것

- **변환 엔진을 한 목록에서 고릅니다.** 설정 › 모델의 `변환 엔진`에 `자동`과 엔진들이 라디오 목록으로 모였습니다.
  - 받지 않은 엔진도 고를 수 있습니다. 고르면 바로 받기 시작하고, 다 받기 전에는 받아 둔 다른 엔진으로 변환합니다.
  - 각 줄에서 모델 이름, 만든 곳, 크기, 상태, 받기·삭제를 한눈에 봅니다. `변환 엔진 직접 추가`도 같은 구역으로 옮겼습니다.
  - 변환 엔진이 아닌 모델(목소리 구간 감지, 참석자 구분 등)은 아래 `다른 기능의 모델`에 따로 묶었습니다.
- **한국어 파인튜닝 엔진을 목록에 더했습니다.** `Qwen3-ASR 1.7B 한국어 (bf16)`(TeamUNIVA, 4.7GB, Apache-2.0)입니다. 자주 쓰는 단어를 쓸 수 있습니다.
  - 아직 간이 점검만 했습니다(회의 5분 구간에서 반복 루프 없음). 한·영 혼용 정확도는 재지 않았습니다. 직접 써 보고 판단해 주세요.
  - 이 엔진은 언어 자동 감지가 영어로 잘못 보고 구간을 비우는 일이 있어, 빈 글이 나오면 그 구간만 한국어로 다시 변환합니다.
- **녹음 중 입력 장치가 바뀌어도 녹음이 이어집니다.** AirPods 같은 블루투스 장치를 연결하거나 끊을 때 녹음 프로그램이 통째로 멈추던 문제(이슈 #57)를 고쳤습니다. 장치가 아직 준비되지 않았으면 오류로 알리고 2초 뒤 다시 연결합니다. 이 Mac의 마이크와 에코 제거 녹음이 정상인 것은 확인했지만, 실제 장치를 바꾸는 상황은 재현해 확인하지 못했습니다. 같은 문제가 또 생기면 알려 주세요.
  - 멈춘 녹음이 있다면 `recordings` 폴더의 소리 파일은 남아 있고, 사이드바 `변환 대기 중인 녹음`에서 변환할 수 있습니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 › 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`
- 노트·모델·설정 파일은 그대로입니다.

## English

Tractus turns recordings and memos into text on your Mac, then summarizes, searches and answers questions about them. **New in 0.5.2: a simpler way to choose the transcription engine, and a fix for recording stopping when the input device changes.**

- **Choose the engine from one list.** In Settings › Models, `Transcription engine` is now a radio list with `Automatic` and each engine. You can pick an engine you haven't downloaded: it starts downloading right away, and until it finishes the engines you already have are used. Each row shows the model name, publisher, size, status and download/delete; `Add a transcription engine` moved into the same section. Models that aren't transcription engines sit below under `Models for other features`.
- **A Korean fine-tuned engine is listed.** `Qwen3-ASR 1.7B Korean (bf16)` (TeamUNIVA, 4.7GB, Apache-2.0) supports custom vocabulary. It has only had a quick check (no repetition loops over a 5-minute stretch of a meeting); mixed Korean–English accuracy wasn't measured. When its language auto-detection returns nothing for a chunk, that chunk is transcribed again as Korean.
- **Recording survives an input-device change.** Connecting or disconnecting a Bluetooth device such as AirPods during a recording used to abort the recorder (issue #57). If the device isn't ready, it now reports an error and reconnects after 2 seconds. Normal and echo-cancelled recording on a Mac were checked, but a real device switch could not be reproduced here — please report it if it happens again. If a recording was cut short, its audio is still in the `recordings` folder and can be transcribed from `Recordings waiting to transcribe` in the sidebar.
- Install: open the DMG and drag `Tractus.app` to `Applications`; you need `brew install ffmpeg`. The build isn't notarized yet — use System Settings › Privacy & Security › Open Anyway on first launch. Apple Silicon, macOS 14.4+.
