# Tractus v0.2.0

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 하는 노트 앱입니다. **팀 내 시험용이고, 아직 Apple 서명·공증은 받지 않았습니다.**

## 이번 버전: 화면 전체를 새로 디자인했습니다

- **macOS 노트 앱 같은 화면.** 차분한 무채색 바탕에 색은 의미가 있을 때만 씁니다(녹음은 빨강, 메모는 노랑). 글자 크기와 단추 크기를 정리해 더 촘촘하고 읽기 쉽습니다.
- **라이트·다크 모드.** 설정 > 화면 > 테마에서 시스템 설정·라이트·다크를 고릅니다.
- **홈 화면.** 사이드바의 `홈`에서 녹음 시작·글쓰기·파일 가져오기와 최근 노트를 바로 엽니다.
- **뒤로 가기.** 설정·모델 화면 왼쪽 위의 `‹`로 보던 화면에 돌아갑니다.
- **타이틀바를 합친 창.** 창 맨 위의 신호등 단추가 사이드바 위에 놓입니다.
- **AI 서비스 고르기.** 요약 탭과 AI 질문 입력창에서 서비스 로고와 AI 모델 이름을 보고 고릅니다.
- **설정을 간결하게.** 긴 설명을 한두 마디로 줄였습니다.
- 사이드바의 `AI 어시스턴트`(⌘J)로 모든 노트에 질문합니다.

노트·모델·설정 파일은 그대로입니다. 바뀐 것은 화면뿐입니다.

## 받을 파일

| 파일 | 설명 |
| --- | --- |
| `Tractus-0.2.0-arm64.dmg` | 설치 파일 (Apple Silicon 전용) |
| `Tractus-0.2.0-arm64.dmg.sha256` | 체크섬. `shasum -a 256 -c Tractus-0.2.0-arm64.dmg.sha256` |
| `Tractus.app.tar.gz`, `.sig`, `latest.json` | 앱 안 업데이트가 쓰는 파일입니다. 직접 받을 필요는 없습니다. |

## 업데이트·설치

- **v0.1.1을 쓰고 있다면:** 설정 > 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치하거나 v0.1.0이라면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`

## 요구 사항

- Apple Silicon(M1 이상), 메모리 16GB 이상 권장(8GB는 저사양 구성)
- macOS 14.4 이상(설계상 최소)

## 확인하지 못한 것

- v0.1.1 → v0.2.0 앱 안 업데이트는 이 릴리스로 처음 끝까지 돌아갑니다.
- 깨끗한 Mac과 macOS 14.4~15에서는 시험하지 못했습니다.
