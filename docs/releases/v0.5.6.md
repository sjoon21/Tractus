# Tractus v0.5.6

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 이번 버전은 새 기능보다 **화면 정리**에 집중했습니다. 설명 글 대신 화면이 상태를 보여 주고, 같은 일을 하는 단추는 한 곳에만 둡니다. (English below)

## 이번 버전에서 바뀐 것

- **녹음 화면에 흐르는 파형이 생겼습니다.** 초록 막대와 dB 숫자 대신 최근 약 15초의 소리 크기가 가는 막대로 왼쪽으로 흘러갑니다. 말소리가 잘 들어가는지 한눈에 보입니다.
  - 일시정지하면 파형이 멈춥니다. 정확한 dB는 파형에 마우스를 올리면 보입니다.
  - 화상·하이브리드 녹음은 시스템 오디오 파형이 아래에 옅게 보입니다.
- **녹음 방식은 녹음 단추 옆 `▾`에서 고릅니다.** 사이드바에 늘 떠 있던 `대면 녹음`/`화상·하이브리드` 선택 칸을 없앴습니다. 지금 방식은 녹음 단추 안의 아이콘(사람 = 대면, 모니터 = 화상)으로 보입니다. 단추 글자는 `녹음`으로 줄였습니다.
- **녹음 중 화면의 긴 설명을 줄였습니다.**
  - 시계 아래에는 녹음 방식 이름만 보입니다. 설명은 마우스를 올리면 보입니다.
  - 일시정지 안내 상자를 없앴습니다. 멈추고 흐려진 시계와 `계속` 단추가 상태를 보여 줍니다. 마이크 사용 표시가 켜져 있다는 안내는 `계속` 단추에 마우스를 올리면 보입니다.
  - 메모 입력칸은 `메모 (Enter)`, 녹음을 끝낸 뒤 묻는 창과 변환 전 노트의 안내도 한두 문장으로 줄였습니다.
- **홈을 정리했습니다.** 사이드바의 녹음 단추·새 노트 메뉴와 같은 일을 하던 `녹음 시작`·`글쓰기`·`파일 가져오기` 큰 타일을 없앴습니다. 곧 시작하는 일정, 최근 노트, 단축키에서 상자와 아이콘 장식을 걷었습니다.
- **사이드바 검색칸이 하나가 되었습니다.** 노트가 많을 때 목록 위에 따로 뜨던 `목록에서 제목 찾기`를 없앴습니다. 맨 위 `노트 검색`이 제목으로 바로 열기와 내용 검색을 모두 합니다.
- **변환 엔진이 없을 때 안내가 한 줄 단추가 되었습니다.** `녹음만 저장됩니다 · 변환 엔진 설치`를 누르면 모델 화면이 열립니다(ffmpeg가 없으면 시작 점검).
- **빈 화면 안내를 하나의 모양으로 맞췄습니다.** 요약·회의록 탭과 빈 대화 내용은 제목 한 줄과 짧은 설명으로 보입니다.
- **AI 어시스턴트를 다듬었습니다.** 입력창의 굵은 파란 초점 테두리를 걷었고, 답을 기다리는 동안 `관련 대화를 찾는 중…` 같은 글자 위로 빛이 지나갑니다.

## 알아 둘 것

- 기능과 데이터는 바뀌지 않았습니다. 화면의 모양과 문구만 바뀌었습니다.
- 녹음 방식은 마지막으로 고른 값이 그대로 남습니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 › 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`
- 노트·모델·설정·사전 파일은 그대로입니다.

## English

Tractus turns recordings and memos into text on your Mac, then summarizes, searches and answers questions about them. **0.5.6 is a design cleanup: the screen shows state instead of explaining it, and each action lives in one place.**

- **Live waveform.** The recording screen shows the last ~15 seconds of sound as thin bars moving left, instead of a green bar and a dB number. It stops while paused; hover to see the exact dB. Hybrid recordings show a fainter system-audio waveform below.
- **Recording mode in the record button.** Pick `In person` or `Video call or hybrid` from the `▾` next to the record button; an icon on the button shows the current mode. The sidebar no longer has a separate mode switch, and the button now just says `Record`.
- **Shorter text while recording.** Only the mode name under the clock, no pause notice box (the frozen clock and `Resume` button show it; the microphone-indicator note is in the `Resume` tooltip), `Memo (Enter)` as the memo placeholder, and one- or two-sentence notes after recording and on untranscribed notes.
- **Tidier home.** The big `Start recording` / `Write` / `Import file` tiles, which duplicated the sidebar, are gone, and the upcoming event, recent notes and shortcuts drop their boxes and icon decorations.
- **One search box in the sidebar.** The separate `Filter by title` box is gone; `Search notes` at the top opens notes by title and searches contents.
- **Missing engine is one clickable line.** `Recordings only · Install a transcription engine` opens Models (or the setup check if ffmpeg is missing).
- **One empty-state style** for the Summary and Minutes tabs and empty transcripts, and a **lighter AI assistant** input with a shimmer on `Finding relevant lines…` while you wait.
- Features and data are unchanged; only the look and wording changed.
- Install: open the DMG and drag `Tractus.app` to `Applications`; you need `brew install ffmpeg`. The build isn't notarized yet — use System Settings › Privacy & Security › Open Anyway on first launch. Apple Silicon, macOS 14.4+.
