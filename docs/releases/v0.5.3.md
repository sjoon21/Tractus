# Tractus v0.5.3

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 이번 버전은 0.5.2에 더한 한국어 파인튜닝 변환 엔진을 가볍게 했습니다. (English below)

## 이번 버전에서 바뀐 것

- **`Qwen3-ASR 1.7B 한국어` 엔진이 8bit 변환본이 됐습니다.** 0.5.2에서는 원본(bf16) 4.7GB를 받아야 했는데, 이제 2.5GB입니다. 같은 회의 5분 구간에서 원본보다 약 30% 빨랐습니다.
  - 정확도는 원본과 거의 같게 나왔습니다(같은 구간 출력 차이 CER 2.5, 반복 루프 없음). 다만 5분 구간 하나로 본 간이 점검이고, 한·영 혼용과 공개 벤치마크는 재지 않았습니다.
  - 변환본은 제작자 TeamUNIVA의 모델을 8bit로 바꿔 올린 것입니다(`voyagar/Qwen3-ASR-1.7B-ko-mlx-8bit`, Apache-2.0).
- **0.5.2에서 이 엔진(4.7GB)을 이미 받으셨다면:** 설정 › 모델의 `변환 엔진`에서 이 엔진을 한 번 더 받아 주세요(2.5GB). 고른 엔진 설정은 그대로이고, 새로 받는 동안에는 받아 둔 다른 엔진으로 변환합니다. 옛 4.7GB 폴더는 설정 › 모델의 `사용하지 않는 폴더 … 정리` 단추로 지울 수 있습니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 › 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`
- 노트·모델·설정 파일은 그대로입니다.

## English

Tractus turns recordings and memos into text on your Mac, then summarizes, searches and answers questions about them. **New in 0.5.3: the Korean fine-tuned engine added in 0.5.2 is now lighter.**

- **`Qwen3-ASR 1.7B Korean` is now an 8-bit conversion.** 0.5.2 needed the 4.7GB original (bf16); it is now 2.5GB and about 30% faster on the same 5-minute stretch of a meeting. Accuracy came out close to the original (2.5 CER difference on that stretch, no repetition loops) — but this is only a quick check on one 5-minute stretch; mixed Korean–English speech and public benchmarks were not measured. The converted model is TeamUNIVA's model quantized to 8-bit (`voyagar/Qwen3-ASR-1.7B-ko-mlx-8bit`, Apache-2.0).
- **If you already downloaded the 4.7GB engine in 0.5.2:** open Settings › Models › `Transcription engine` and download this engine once more (2.5GB). Your engine choice stays, and until the new download finishes the engines you already have are used. The old 4.7GB folder can be removed with the `Clean up … unused folder` button in Settings › Models.
- Install: open the DMG and drag `Tractus.app` to `Applications`; you need `brew install ffmpeg`. The build isn't notarized yet — use System Settings › Privacy & Security › Open Anyway on first launch. Apple Silicon, macOS 14.4+.
