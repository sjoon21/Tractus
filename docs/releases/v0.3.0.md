# Tractus v0.3.0

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 

## 이번 버전에서 새로 생긴 것

- **노트 완성.** 녹음하면서 적은 메모를 바탕으로, 대화 내용에서 세부를 붙여 완성된 노트를 만듭니다. 줄마다 근거가 된 대화 위치로 갈 수 있습니다.
- **Obsidian으로 보내기.** 노트 하나를 볼트의 `Tractus/` 폴더에 Markdown으로 보냅니다. 완성된 노트·요약·할 일 체크박스·대화 내용(접어서)이 들어갑니다.
- **macOS 캘린더 연결.** 설정 &gt; 캘린더에서 연결하면, 곧 시작하는 일정이 홈에 카드로 보입니다. `녹음`을 누르면 일정 제목으로 녹음하고, 참석자 이름을 음성 인식 힌트와 참석자 이름 고르기에 씁니다. Google·Exchange 계정도 macOS 캘린더에 추가돼 있으면 읽습니다.
- **처음 쓰는 사람을 위한 안내.** 홈의 `Tractus 시작하기` 목록, 모델·AI 키 없이 둘러볼 수 있는 예시 노트, 화면 곳곳의 기능 안내가 생겼습니다. 설정 &gt; 도움말에서 다시 보거나 끌 수 있습니다.
- **Claude Code에서 내 노트에 묻기.** Claude Code 플러그인을 설치하면 "지난주에 뭘 하기로 했지?" 같은 질문에 내 노트를 찾아 노트 제목과 시각을 근거로 답합니다. 노트는 이 Mac에서 읽습니다.
  ```
  /plugin install tractus --marketplace sjoon21/Tractus
  ```

## 더 빠르고 안전하게

- 노트가 많아도 목록을 바로 다시 그립니다(바뀐 노트만 다시 읽습니다). 새 메모와 예시 노트는 바로 열립니다.
- 요약이 끝나면 검색 준비를 기다리지 않고 바로 보입니다.
- 설정 저장이 끊겨도 설정 파일이 깨지지 않고, 동시에 저장해도 값을 잃지 않습니다.
- 플러그인은 데이터 폴더 밖의 파일을 읽지 않고, 다른 프로젝트 폴더의 `.env`를 읽지 않습니다.

## 업데이트하기 전에 알아 둘 것

- 이미 쓰던 사람에게도 홈의 `Tractus 시작하기` 목록이 한 번 보입니다. `닫기`를 누르면 사라집니다.
- 앱을 새로 서명했기 때문에 마이크·시스템 오디오 권한을 다시 물을 수 있습니다.
- 캘린더 권한은 설정에서 `캘린더 연결`을 누를 때만 묻습니다.

노트·모델·설정 파일은 그대로입니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 &gt; 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`

## 요구 사항

- Apple Silicon(M1 이상), 메모리 16GB 이상 권장(8GB는 저사양 구성)
- macOS 14.4 이상(설계상 최소). 캘린더 연결은 macOS 14 이상의 `캘린더 전체 접근` 권한을 씁니다.
