# Tractus v0.4.2

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 이번 버전은 텍스트 변환 엔진을 앱 안에서 고르고 바꿀 수 있게 했고, 녹음 중에 남긴 메모를 고치고 지울 수 있게 했습니다. (English below)

## 이번 버전에서 새로 생긴 것

- **변환 엔진 고르기.** 모델 화면에서 텍스트 변환에 쓸 기본 엔진을 고릅니다. `자동으로 고르기`는 전처럼 메모리에 맞는 엔진을 씁니다.
  - 고른 엔진을 받아 두지 않았으면 메모리에 맞는 기본 엔진으로 변환하고 알려 줍니다.
  - 쓰지 않는 엔진은 모델 화면에서 지울 수 있습니다.
- **변환 엔진 직접 추가.** 목록에 없는 모델도 Hugging Face 저장소 ID로 추가합니다. Qwen3-ASR·Whisper·SenseVoice 계열(MLX 형식)을 지원합니다.
  - 받은 뒤 모델 종류를 확인하고, 필요한 파일이 없는 저장소는 거절합니다.
  - 한국어로 파인튜닝한 모델을 직접 시험해 볼 때 쓰세요. 실시간 텍스트 변환은 전처럼 Qwen3-ASR 0.6B를 씁니다.
- **녹음 중 메모·북마크 고치기·지우기.**
  - 녹음 중(일시정지 포함)에는 녹음 화면의 메모 목록에서, 녹음이 끝난 뒤에는 노트의 대화 내용 사이 메모 줄에서 고칩니다.
  - 메모는 두 번 누르거나 연필을 눌러 고치고, 비우면 지워집니다. 북마크는 휴지통으로 지웁니다.

## 고친 것

- 긴 메모를 남기면 녹음 화면에서 시각(`1:15`)과 `메모` 표시가 글자마다 쪼개지던 문제를 고쳤습니다. 노트에서도 시각이 메모 첫 줄에 맞게 놓입니다.
- 메모 입력칸이 글에 맞춰 아래로 늘어납니다. 긴 메모가 옆으로 밀려 가려지지 않습니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 › 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`
- 노트·모델·설정 파일은 그대로입니다. 앱을 새로 서명했기 때문에 마이크·시스템 오디오 권한을 다시 물을 수 있습니다.

## English

Tractus turns recordings and memos into text on your Mac, then summarizes, searches and answers questions about them. **New in 0.4.2: choose and swap transcription engines, and edit or delete memos you left while recording.**

- **Choose a transcription engine.** On the Models screen, pick the default engine for transcripts, or `Choose automatically` to keep using the one that fits your memory. If the chosen engine isn't downloaded, Tractus falls back to the default and tells you. Remove engines you don't use from the same screen.
- **Add a transcription engine.** Add a model that isn't listed by its Hugging Face repo ID. Qwen3-ASR, Whisper and SenseVoice families (MLX format) are supported; repos missing required files are refused. Live transcription still uses Qwen3-ASR 0.6B.
- **Edit and delete recording memos.** While recording (or paused), edit memos and bookmarks in the list on the recording screen; afterwards, edit them in the note. Double-click a memo or use the pencil to edit, clear it to delete, and use the trash icon to delete a bookmark.
- **Fixed:** long memos no longer break the time and `Memo` label onto separate lines, the time lines up with the first line of the memo in notes, and the memo box grows with the text.
- Install: open the DMG and drag `Tractus.app` to `Applications`; you need `brew install ffmpeg`. The build isn't notarized yet — use System Settings › Privacy & Security › Open Anyway on first launch. Apple Silicon, macOS 14.4+.
