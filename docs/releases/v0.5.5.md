# Tractus v0.5.5

녹음과 메모를 내 Mac 안에서 텍스트로 바꾸고, 요약·검색·AI 질문까지 가능한 앱입니다. 이번 버전은 받아 적기 정확도를 사용자가 직접 높이는 `사전`과, 노트를 빨리 찾아 다루는 ⌘K·이번 주 띠를 더했습니다. (English below)

## 이번 버전에서 바뀐 것

- **`자주 쓰는 단어`가 `사전`이 되고 화면이 따로 생겼습니다.** 사이드바 위 `사전`에서 엽니다.
  - Enter로 단어를 더합니다. 쉼표나 줄바꿈으로 나눈 목록을 붙여 넣으면 미리 보고 한 번에 더합니다.
  - 줄마다 고치거나 지울 수 있습니다. 지운 뒤에는 알림의 `되돌리기`로 되살립니다.
  - **고쳐 쓴 낱말:** 대화 내용에서 직접 고친 낱말 중 사전에 넣을 만한 것을 칩으로 보여 줍니다. 누르면 더하고, ×를 누르면 다시 보이지 않습니다. 글자를 저절로 바꾸지는 않습니다.
  - 텍스트로 변환할 때 **최근에 더한 단어부터** 씁니다. 단어가 50개를 넘어도 방금 넣은 단어가 빠지지 않습니다.
  - Qwen 계열이 아닌 변환 엔진을 고르면 `사전 단어를 쓰지 않습니다`라고 알려 줍니다.
- **⌘K 빠른 실행 창이 생겼습니다.** ⌘K를 누르면 화면 가운데 창이 열립니다.
  - 비어 있을 때는 최근에 고친 노트 5개와 앱 동작(녹음 시작·글쓰기·파일 가져오기·AI 어시스턴트·사전·설정 등)이 보입니다.
  - 입력하면 제목이 맞는 노트, 이름이 맞는 동작, 맞는 폴더·태그가 나옵니다. 맨 아래 `내용에서 찾기`로 노트 내용을 검색합니다.
  - 노트를 연 채 열면 `이 노트` 묶음에서 즐겨찾기, 태그 편집, 내보내기(Markdown·Word·PDF 등), Obsidian으로 보내기, 폴더로 옮기기를 할 수 있습니다. 자주 쓰지 않는 것은 입력해야 나옵니다(예: `pdf`, `폴더`).
- **홈에 `이번 주` 띠가 생겼습니다.** 월요일부터 일요일까지 날마다 캘린더 일정과 그날 만든 노트를 보여 줍니다.
  - 캘린더를 연결하지 않아도 노트는 보입니다.
  - 오늘 아직 끝나지 않은 일정에는 녹음 단추가 있습니다.
  - 일정으로 녹음한 노트는 그 일정 바로 아래에 들여 써서 보입니다. 반복 일정은 회차마다 따로 잇습니다.
- **안내 말풍선과 빈 요약 화면을 고쳤습니다.**
  - 안내 말풍선이 열린 AI 어시스턴트 서랍 위에 뜨거나 대화 줄을 가리지 않습니다.
  - 요약이 없을 때 `요약 만들기` 단추를 가리키는 안내 상자가 보입니다.
- **앱이 조금 가벼워졌습니다.** 목소리 프로필 모델을 다른 실행 방식으로 바꿔 큰 라이브러리 하나를 뺐습니다. 등록해 둔 목소리는 다시 등록하지 않아도 되고 결과도 같습니다.
- 내부 구조를 많이 정리했습니다(노트 화면·작업 순서·명령 모듈). 동작은 바뀌지 않았습니다.

## 알아 둘 것

- 예전 버전에서 일정으로 녹음한 노트는 일정 제목이 같을 때만 일정 아래로 이어집니다. 캘린더에서 제목을 바꾸면 따로 보입니다.
- 사전 화면은 영어 화면에서 `Vocabulary`로 보입니다.

## 업데이트·설치

- **v0.1.1 이상을 쓰고 있다면:** 설정 › 업데이트에서 `업데이트 확인` → `업데이트 설치` → `다시 열기`.
- **새로 설치한다면:** DMG를 열고 `Tractus.app`을 `Applications`로 끌어다 놓습니다.
  - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기" (또는 `xattr -dr com.apple.quarantine /Applications/Tractus.app`)
  - **ffmpeg가 필요합니다:** `brew install ffmpeg`
- 노트·모델·설정·사전 파일은 그대로입니다.

## English

Tractus turns recordings and memos into text on your Mac, then summarizes, searches and answers questions about them. **New in 0.5.5: a Vocabulary screen, a ⌘K command window and a This week strip on the home screen.**

- **Vocabulary.** The old frequent-words list is now its own screen (`Vocabulary` at the top of the sidebar). Press Enter to add a word, or paste a comma- or line-separated list and add it in one go. Edit or delete any word; `Undo` in the notice brings a deleted word back. **Words you corrected** shows words you fixed in transcripts as chips: click to add, × to hide. Nothing is replaced automatically. Transcription now uses the **most recently added words first**, so new words are not dropped once you pass 50. If you pick a non-Qwen engine, the screen tells you the vocabulary is not used.
- **⌘K.** Opens a window in the middle of the screen. Empty, it shows your 5 most recently edited notes and app actions. Type to find notes by title, actions by name, and folders & tags; `Search contents` at the bottom searches inside notes. With a note open, **This note** lets you favorite it, edit tags, export (Markdown, Word, PDF and more), send it to Obsidian or move it to a folder. Less common actions appear only when you type (e.g. `pdf`, `folder`).
- **This week.** The home screen shows Monday to Sunday with each day's calendar events and the notes made that day. Notes show even without a calendar. Events today that haven't ended get a record button. Notes recorded from an event sit right under that event; recurring events link per occurrence.
- **Fixes:** tips no longer pop up over the open AI assistant drawer or cover transcript lines, and an empty summary shows a box pointing to `Create summary`.
- **Lighter app:** the voice profile model runs a different way, so one large library is gone. Enrolled voices keep working without re-enrolling, with the same results.
- Notes recorded from an event in older versions link only while the event title is unchanged.
- Install: open the DMG and drag `Tractus.app` to `Applications`; you need `brew install ffmpeg`. The build isn't notarized yet — use System Settings › Privacy & Security › Open Anyway on first launch. Apple Silicon, macOS 14.4+.
